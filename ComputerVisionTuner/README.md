# Computer Vision Tuner
Built for my high school robotics team to tune the RGB values for our Computer vision pipeline.

A computer vision tool that allows users to play with different RGB values to see which values are needed to detect certain colors
## Features

- **RGB changers**: Sliders pop up allowing the user to change the rgb values as simply as clicking and dragging
- **Real time color adjusting**: The video from the camera is updated live when the RGB values are adjusted


## Technical Details

- Built in Python
- Uses OpenCV for all the sliders, camera, and values altering
